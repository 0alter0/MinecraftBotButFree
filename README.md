# MinecraftBotButFree
MBBF - MinecraftBotButFree

# What?
Have you ever wanted to use MinecraftBot (the website that has a paid service) but can't because you actually have cognitive thought and that it's worthless?

If yes, then this is for you, because I'm quite sure MB (MC Bot) uses Mineflayer, and that's quite easy to code in!

If no, well you're still in luck, this is a very feature rich Mineflayer thingy.
